# Welcome to Columns

Columns is a lightweight Markdown reader for ultrawide screens. It shows one document as side-by-side columns of text, so a wide screen holds several pages of it at once.

To read your own file, choose **File > Open…** (⌘O), or drag a Markdown file onto this window or onto the Columns icon in the Dock. **File > Open Recent** lists the files you read before, and each one opens at the place you had reached. When you open Columns again, it shows the files that were open if your Mac keeps windows when you quit (System Settings > Desktop & Dock). To do the other way once, hold ⌥ in the Columns menu: it shows **Quit and Keep Windows** or **Quit and Close All Windows** (⌥⌘Q).

## How the text flows

The text runs down the first column, then continues at the top of the next one, like a newspaper. All the columns scroll together.

Where one column ends and the next begins, the last two lines are shown in both. A dotted ribbon joins the two places, so your eye knows where to go next. The dots move as you scroll.

## Choose how many columns

Press ⌘1 to ⌘6 for one to six columns. On a laptop, two or three read well. On an ultrawide screen, try five or six.

## Find your way

**Go > Go to Section** lists the headings of the document (the first three levels) and marks the section you are reading. Choose one to go straight there.

After you go to a section, follow a link inside the document or find a word, **Go > Back** (⌘[) returns to the place you left. **Go > Forward** (⌘]) goes there again.

The bar at the right edge shows how far you are in the document. Drag it to move quickly.

A link to a web page opens in your browser. A link to another Markdown file opens that file in Columns, at the heading the link names. Rest the pointer on a link to see where it goes.

To keep a copy, choose **File > Export as PDF…**. The copy is in pages, with every section open.

## Tabs and the sidebar

Every file you open becomes a tab of the window in front, as in a web browser. The tabs are in the sidebar on the left, so the text keeps the whole height of the window. **New Tab** at the end of the list (⌘T) opens another file as a tab; **File > New Window…** (⌘N) opens one in a window of its own.

Drag a tab up or down the sidebar to reorder it, out of the window to give it a window of its own, or onto another window's sidebar to move it there. **File > Reopen Closed Tab** (⇧⌘T) brings back the tab you closed last.

**Show icons only** at the foot of the sidebar makes it narrow, with two letters for each tab; **Show tab names** makes it wide again. The button beside the window's three dots hides the sidebar (⌃⌘S). While it is hidden, rest the pointer on that button to see the sidebar for a moment over the text, and click it to keep it. **Reading settings** (Aa) is at the foot of the sidebar too.

## Collapse a section

Move the pointer over the page and an arrow shows beside each heading. Click it to collapse that section; click it again to expand it. Hold ⌥ and click to collapse or expand every section at the same level. Columns remembers which sections you collapsed in each file.

To collapse or expand everything, use **View > Collapse All Sections** and **Expand All Sections**.

## Make it yours

Open **Reading settings** (⌘,, or Aa at the foot of the sidebar) to change the number of columns, the text size, the theme (System, Light, Sepia or Dark) and the font.

Two switches are there too. **Bigger dots** makes the dotted ribbons easier to see. **Bold word starts** shows the first letters of each word in bold, which some people find faster to read.

## Your file stays yours

Columns only reads. It never changes your file. When the file changes on disk, for example while you or an AI agent edit it in another app, Columns shows the new text at once and marks what changed for a moment.

If you rename or move the file, Columns follows it. If it is deleted, Columns keeps the last version on screen and tells you so.

## Keyboard shortcuts

| To do this | Press |
| --- | --- |
| Open a file in a new tab | ⌘T |
| Open a file in a new window | ⌘N |
| Go to the next or previous tab | ⇧⌘] and ⇧⌘[ (or ⌃⇥ and ⌃⇧⇥) |
| Close the tab, or the whole window | ⌘W and ⇧⌘W |
| Show or hide the sidebar | ⌃⌘S |
| Show tab names or icons only | ⌥⌃⌘S |
| Reopen the tab you closed last | ⇧⌘T |
| Scroll one screen down or up | Space and ⇧Space |
| Scroll a few lines | ↓ and ↑ |
| Go to the beginning or the end | ⌘↑ and ⌘↓ |
| Go to the previous or next section | ⌥⌘↑ and ⌥⌘↓ |
| Go back or forward after a jump | ⌘[ and ⌘] |
| Show 1 to 6 columns | ⌘1 to ⌘6 |
| Make the text bigger or smaller | ⌘+ and ⌘− |
| Return to the actual size | ⌘0 |
| Find in the document | ⌘F |
| Go to the next or previous match | ⌘G and ⇧⌘G |
| Find the selected text | ⌘E, then ⌘G |
| Collapse or expand all sections | ⌥⇧⌘← and ⌥⇧⌘→ |
| Collapse or expand every section at one level | ⌥-click a section arrow |
| Open Settings | ⌘, |
| Open a file | ⌘O |
| Reload the file | ⌘R |
| Show the file in Finder | ⇧⌘R |
| Print | ⌘P |
| Enter or leave full screen | ⌃⌘F |

You can also right-click the page for the commands you use most.

## Come back here

This page is always at **Help > Columns Help** (⌘?). **Help > Keyboard Shortcuts** opens the table above.

Columns is free and open source. **Help > Columns on GitHub** opens its page, and **Help > Send Feedback…** lets you report a problem or ask for something.
